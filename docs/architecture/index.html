Architecture

PogopoOS separates board-specific communication from reusable services and application behavior. The goal is a small set of understandable layers, not documentation for every source file.

Hardware and drivers

Board pin mappings live in one board definition, while each component owns its peripheral protocol. The display driver controls SPI and VCOM, storage owns SDMMC mounting, audio owns I²S, and I²C services communicate with the input expander, IMU, and charger.

Services

Services expose device behavior instead of raw buses. For example, an app asks the input service for button state, draws through the graphics API, and submits audio without directly configuring the TCA9555, Sharp LCD, or MAX98357A.

PogopoOS layer

The OS layer initializes services, registers applications, controls which app owns input, and manages overlays such as the quick menu and shutdown animation. It also coordinates save flushing and display clearing during power-off.

Applications and runtimes

Applications receive shared service references from the app manager. The Game Boy runtime adds emulator-specific CPU, audio, ROM-cache, and framebuffer work, but it still enters and exits through the same application lifecycle as system screens.

Task and core organization

FreeRTOS work is separated by latency and ownership. The current Game Boy path runs emulation and input on Core 1. Core 0 handles fixed-clock I²S output, decoupled APU generation, motion and power services, VCOM maintenance, and the lower-priority PogopoOS UI/display loop.

This split is a performance decision for the current firmware, not a permanent ABI. Changes are validated with serial timing, underrun, heap, cache, and I²C diagnostics.

Typical data flow

Input
TCA9555 → input service → app manager → active application
Graphics
Application canvas → 1-bit framebuffer → dirty/full SPI transfer → Sharp LCD
Game Boy audio
MiniGB APU → internal ring buffer → fixed-rate I²S task → MAX98357A
Shutdown
Power hold → overlay → save flush → physical LCD clear → BQ24295 ship mode
