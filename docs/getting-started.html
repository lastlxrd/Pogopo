getting started

Requirements

  • pogopo ESP32-S3 hardware
  • ESP-IDF 6.0.2 terminal
  • USB data cable
  • FAT32 microSD card

Build and flash

git clone https://github.com/pogopo/pogopoOS.git
cd pogopoOS
idf.py fullclean
idf.py build
idf.py -p COM7 flash monitor

Replace COM7 with the serial port shown on your computer.

SD-card layout

/gameboy/
  Game Name.gb

/playdate/
  Game Name.pdx/
    pdxinfo
    main.pdz
    ...

Playdate games must be extracted .pdx directories, not ZIP files. A package containing only a native ARM pdex.bin cannot run on the ESP32-S3.

Controls

ControlOS action
D-padNavigate lists and games
AOpen or confirm
BBack
STARTRescan game browser; game-specific action while playing
Power tapOpen or close the quick panel
Power holdPlay the shutdown animation and power off

First check

After flashing, confirm that the startup animation, launcher, Game Boy browser, Playdate browser, audio and Power quick panel all work before changing configuration.
