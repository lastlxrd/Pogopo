# STEP11.6.21 — PogoDate menu key repeat and system glyph fallback

## Before

STEP11.6.20 let Hillslide finish all 35 Lua modules and report `PogoDate Lite
ready`. Its main menu appeared, proving that font families and callable scene
classes were working. Pressing right or down then stopped input dispatch at
`scenes/MainMenu.lua:143` because `playdate.timer.keyRepeatTimer` was nil.
Characters used as menu decorations also appeared as `?` on both sides of
each label.

## Cause

PogoDate implemented ordinary millisecond timers and frame timers but omitted
the SDK's two key-repeat constructors. Hillslide uses that standard helper to
move once on the initial D-pad press and continue moving while the direction
is held.

The PFT renderer handled missing custom-font characters by substituting the
custom font's question-mark glyph. Playdate instead falls back to its system
font when possible. Nontendo-style fonts commonly omit arrows and menu
brackets, which exposed the difference.

## Changes

- added `playdate.timer.keyRepeatTimer(callback, ...)` with the SDK defaults:
  immediate callback, 300 ms initial delay and 100 ms repeats;
- added `keyRepeatTimerWithDelay(initialDelay, repeatDelay, callback, ...)`;
- preserved the SDK callback rule: explicit arguments are forwarded, while a
  callback without arguments receives the timer object;
- returned ordinary removable/pausable timer tables and switched from the
  initial delay to the repeat delay after the first timed firing;
- added system-font fallback for ASCII characters missing from compiled PFTs;
- mapped common Unicode left/right/up/down arrows and triangle symbols to
  compact system direction glyphs;
- kept text measurement and glyph-image extraction consistent with rendering.

## Result

A dedicated host regression checks immediate, initial-delay and repeat-delay
firings, callback arguments, the timer-object callback form and removal. It
also loads a real PFT which lacks `<`, compares its fallback glyph pixel by
pixel with the system font, and verifies Unicode directional widths.

The rebuilt suite passes the STEP11.6.20 callable-scene regression, the real
three-PFT family test, sprite/tilemap/image/pathfinder coverage, input
responders, crank, synth, deep-SFX startup, Maze for 900 frames, Duel Of
Shadows for 1,800 frames, Celeste for 300 frames, Godspeed through game over
and Frogger startup. WOOD's eight progression captures are byte-identical to
STEP11.6.20.

The next hardware proof is Hillslide menu navigation: each D-pad press should
move the selection without an input error, holding a direction should repeat,
and the decoration characters should no longer be question marks.
