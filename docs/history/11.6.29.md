# STEP11.6.29 — next-game compatibility

This step follows the STEP11.6.28 API pass and closes the next failures exposed
by Novena, Illumination, Loopsy and XTRIS.

## Runtime fixes

- `import()` now returns values produced by a module on its first execution.
  This matches Playdate import semantics and fixes value modules such as the
  Hashids library used by Loopsy.
- `playdate.graphics.pushContext()` accepts an omitted or nil image and targets
  the display framebuffer while preserving the previous context.
- Package resource paths normalize leading `./` segments.
- `imagetable.new(path)` can load a directory containing a contiguous numbered
  sequence of compiled `.pdi` frames in addition to a single `.pdt` file.
- Text alignment accepts SDK constants and the strings `left`, `center`,
  `centre`, and `right`.
- Audio player userdata accepts `setBufferSize()` as a preload-compatible hint.

## Compatibility objects

- Added lifecycle-compatible `playdate.sound.channel`.
- Added `playdate.sound.track` note storage and track metadata.
- Added `playdate.sound.sequence` track, tempo, loop, play/stop and timing state.
- Added numeric and point `playdate.graphics.animator` interpolation.

PogoDate still does not mix sequence/track note events into native audio. Pulp
games can initialize and run, but their sequenced MIDI-style music may remain
silent until the sequence mixer is implemented.

## Regression coverage

- Lua 5.4 32-bit syntax validation passed.
- C++ runtime syntax compilation passed.
- Compatibility API test passed for channel, track, sequence, animator,
  nil-context, string alignment, buffer size, and PDI directory image tables.
- Hillslide passed all nine scenes, including 530 Training frames and 1030 Game
  frames, with zero Lua errors.
- Maze stress completed 3000 host ticks with zero Lua errors.
