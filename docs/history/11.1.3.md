# STEP11.1.3 — Celeste native fill and Sharp 2x fast path

## Before

Celeste ran at only about 13–14 FPS because Lua rendering and final framebuffer scaling were too expensive.

## Changes

Fullscreen 2x scaling, filled rectangles and common image blits were replaced with optimized native fast paths. :contentReference[oaicite:0]{index=0}

## Result

After building and flashing, Celeste reached approximately 29–31 Lua FPS and 28–30 LCD FPS with no Lua errors, although original Playdate sound assets were still unsupported.
