# STEP12.1 — SharpBit startup linker fix

## Before

STEP12.0 added the startup animation, but the Windows build failed during linking because the embedded animation blob used incorrect binary symbols.

## Changes

The startup animation blob was moved to the `pogopo_startup` component root and switched to the stable `_binary_startup_frames_bin_*` linker symbols. :contentReference[oaicite:0]{index=0}

## Result

The firmware now links correctly while keeping the 111-frame startup animation and its behavior unchanged.
