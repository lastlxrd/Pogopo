# STEP11.2.2 — Playdate PDZ opcode compatibility fix

## Before

Valid Playdate PDZ packages were detected but became stuck during execution because their Lua opcode order differed from stock Lua 5.4.

## Changes

Playdate Lua 5.4-beta opcodes are now normalized to the stock Lua 5.4 layout before execution. :contentReference[oaicite:0]{index=0}

## Result

Celeste successfully loaded from SD and ran at approximately 29–31 Lua FPS and 26–30 LCD FPS, while Onebit Frogger reached Lua execution but stopped because the `playdate.file` API was not yet implemented.
