# STEP12.2 — Black power-off screen

## Before

Shutdown explicitly cleared the Sharp Memory LCD to white before entering BQ24295 ship mode.

## Changes

The shutdown path now sends a full-screen black framebuffer with `refresh_full()` instead of using the hardware CLEAR command. :contentReference[oaicite:0]{index=0}

## Result

The firmware no longer forces a white shutdown frame and leaves the LCD framebuffer black for as long as the panel retains power.
