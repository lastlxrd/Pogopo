# STEP 9.5.2 — Complete ASCII font coverage

## Before

The built-in 5 × 7 font did not include every printable ASCII character, so punctuation in Game Boy filenames could appear as unknown-symbol boxes.

## Changes

The system font was expanded to cover the complete printable ASCII range from `0x20` through `0x7E`.

## Result

After building and flashing, apostrophes, hyphens, brackets, commas, ampersands and other ordinary symbols rendered correctly in ROM filenames and across the OS.
