# STEP11.6.31 — coroutine-safe resources, argument compatibility and fatal audio cleanup

This step follows the STEP11.6.30 hardware results for Binairo, Loopsy and
XTRIS.

## Compatibility fixes

- `graphics.drawTextAligned()` and the font method now read their optional
  alignment before `luaL_tolstring()` appends the converted text to the Lua
  stack. Three-argument calls used by Binairo's Continue screen therefore use
  the SDK default alignment instead of treating the text as argument four.
- `graphics.fillRoundRect()` and `graphics.drawRoundRect()` accept finite
  fractional radii and round them for the integer rasterizer. This fixes the
  animated Loopsy transition after pressing A.
- Absolute-looking package resource names such as `/assets/sfx/wobble` are
  resolved from the PDX root. XTRIS now plays its packaged menu sounds instead
  of Pogopo's missing-resource fallback tone.
- Scoreboard callbacks now receive the SDK-shaped status object
  `{code="OK", message=""}` before the result object.

## Coroutine safety

- Images, image tables, serialized frames, dynamic images and system fonts are
  created on the active `lua_State` instead of always using the main thread.
- Timer methods and the timer registry also use the active Lua thread.
  XTRIS creates its level-start timer inside a transition coroutine; the old
  cross-thread stack access killed that coroutine and silently returned to the
  menu.
- Lua update failures now include a traceback when one is available.

## Audio cleanup

- Stopping a PogoDate title or hitting a fatal Lua update error now calls
  `Audio::stopAll()`. Cached game music, sample voices and synth tones stop
  before the launcher plays its one-shot error sound.

## Validation

- Binairo 1.3: 360 frames, zero errors; three-argument aligned text verified.
- XTRIS 1.1.2: real menu navigation, Standard launch and 360 gameplay frames;
  700 total frames, zero errors, zero fallback sounds, clean AddressSanitizer.
- Direct compatibility tests cover fractional rounded rectangles, font/global
  aligned text, scoreboard callback shape and fatal audio cleanup.
- Maze: 900 Lua frames, zero errors under the STEP11.6.31 runtime.
