# STEP11.6.5 — Maze Gridview, responsive BMI270 input and START alias

## Before

STEP11.6.4 brought Maze and Duel Of Shadows into gameplay, but Maze still had a broken LEVELS Gridview path and its accelerometer behavior needed hardware-oriented correction.

## Changes

Maze now uses its bundled Gridview with the missing graphics and geometry APIs, BMI270 data is translated into Playdate display coordinates with lighter filtering and transient-read protection, and the physical START button now acts as Playdate A while a PDX is running. :contentReference[oaicite:0]{index=0}

## Result

Maze now completes dedicated LEVELS and motion regressions without Lua errors, while Duel Of Shadows still reaches its tutorial portal, boss room and combat path successfully.
