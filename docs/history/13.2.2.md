# STEP13.2.2 — Outro without the white first frame

## Before

STEP13.2.1 fixed the Outro alpha channel, but the first Outro frame was still fully white and caused a visible flash when holding Power.

## Changes

The all-white first Outro frame was removed, so the Power hold animation now starts from source frame 2 while keeping the existing alpha-correct rendering, reverse playback and shutdown timing.

## Result

Holding Power now starts the Outro without the initial white flash, while transparent areas still preserve the underlying menu or game.
