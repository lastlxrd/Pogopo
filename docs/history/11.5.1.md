# STEP11.5.1 — Correct Playdate colors and measurable partial LCD updates

## Before

STEP11.5 added real PFT fonts and broader PDX compatibility, but Onebit Frogger still rendered incorrect colors and Sharp partial-update behavior was not visible in runtime diagnostics.

## Changes

Playdate color values are now translated correctly into PogoDate's internal framebuffer format, the 400 x 240 presentation path was optimized, and performance logs now report dirty Sharp rows and transfer timing. :contentReference[oaicite:0]{index=0}

## Result

Onebit Frogger now uses the intended black and white palette while preserving its authored 20 FPS timing, and physical LCD update cost can now be measured directly from serial diagnostics.
