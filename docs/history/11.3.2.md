# STEP11.3.2 — Playdate button-name compatibility

## Before

Onebit Frogger passed `drawRotated()` but stopped because its `btnp()` helper passed string button names instead of numeric Playdate masks.

## Changes

String button names, common prefixes, `buttonJustReleased()` and `getButtonState()` compatibility were added.

## Result

After building and flashing, Frogger still stopped with the same string `btnp()` argument error, while forcing Celeste to 50 FPS made its frame-based gameplay run too fast and did not remove occasional animation stutter.
