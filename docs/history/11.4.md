# STEP11.4 — Broader PDX compatibility and smooth frame pacing

## Before

Celeste worked from SD, but forced 50 FPS made the game run too fast and Onebit Frogger still exposed missing Playdate compatibility.

## Changes

Frogger compatibility, cached sound effects, incremental Lua garbage collection and more accurate frame pacing were added, while Celeste logic was restored to its original 30 FPS timing. :contentReference[oaicite:0]{index=0}

## Result

Celeste and Onebit Frogger now appear stable, but compatibility with other PDX packages is still unverified and will require further testing and API fixes.
