# STEP11.6.28 — five-game API compatibility

## Hardware failures addressed

- XTRIS stopped in `init.lua:18` because `playdate.sound.channel` was absent.
- Loopsy stopped in `scripts/audio.lua:128` because players did not expose
  `setBufferSize()`.
- Illumination stopped in `libraries/panels/Panels.lua:354` because
  `playdate.graphics.animator` was absent.
- Novena stopped in `pulp.lua:1277` while indexing a field named `sequence`.
- Binairo entered its menu but stopped in `ui.lua:876` because its UI passed
  `"left"`, `"center"`, or `"right"` to `drawTextAligned()`.

## Changes

- add mixer-channel construction, source/effect ownership, stereo volume and
  pan state;
- accept `setBufferSize(seconds)` on sample and file players; Pogopo's
  full-buffer decoder records the request without allocating a redundant ring;
- add time-based numeric/table animators with delay, easing, reset, reverse,
  repeat/reverse cycles, progress and remaining-time queries;
- add a silent sound-sequence lifecycle and track container for packages which
  require the API before gameplay; the current backend does not synthesize MIDI;
- accept both SDK integer alignment constants and the common string alignment
  names in graphics- and font-level `drawTextAligned()`.

## Verification

- `compat.lua` passes the 32-bit Lua 5.4 parser;
- the modified C++ runtime passes a host C++17 syntax build;
- a focused Lua test validates channel state, animator progression/reset and
  sequence lifecycle/track access;
- the STEP11.6.27 camera and image-backed sprite changes remain untouched.

The Novena log does not show which table owns the missing `sequence` field.
The new sound-sequence API addresses the Playdate API interpretation, but the
actual Novena PDX is required if the same `pulp.lua:1277` error remains.
