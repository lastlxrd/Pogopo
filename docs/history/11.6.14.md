# STEP11.6.14 — Pulp runtime graphics and audio-clock surface

## Before

STEP11.6.13 added external PDZ load/run support, but Pulp packages could still fail on their first deferred frame when the engine reached cached graphics and sound-clock APIs.

## Changes

PogoDate now implements the Pulp-used `drawPixel()`, class-style image drawing, tiled drawing, graphics clear/inversion and the resettable Playdate sound device clock as generic compatibility APIs. :contentReference[oaicite:0]{index=0}

## Result

The real WOOD package now loads its data and image tables, enters gameplay at its authored 20 FPS and completes a 1800-frame input, rendering and audio stress test with zero errors.
