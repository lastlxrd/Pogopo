# STEP11.6.22 — Hillslide complete API pass

## Before

STEP11.6.21 let Hillslide reach its main menu, navigate with key repeat and
render the circled A/B decorations. Repeated menu movement then stopped in
`Audio.lua:153` because sample players had no `getOffset()` method. Testing one
missing call at a time would leave several later scene and gameplay paths
uncovered.

## Cause

PogoDate's sample/file player stored only a boolean playing state, volume and
rate. It did not expose playback position or volume getters, and a completed
one-shot sample remained marked as playing forever. Hillslide uses those three
behaviours to select a reusable SFX voice. Its later game scene also uses the
SDK spelling `clearStencilImage()` and submits the final score asynchronously.

The game additionally authors the resource path `assets/art/avalanche` while
the compiled file is `Avalanche.pdt`. Playdate resource lookup accepts that
case difference, but a case-sensitive host filesystem did not.

## Changes

- inspected every one of Hillslide's 35 compiled Lua modules instead of only
  following the first runtime error;
- added sample/file-player `getOffset()`, `setOffset()` and `getVolume()`;
- made pause preserve position, stop reset it and non-looping `isPlaying()`
  become false after the real PDA duration;
- added stored loop-range state and preserved an explicit offset on the next
  `play()` call;
- added `graphics.clearStencilImage()` as the SDK alias for clearing the
  current stencil;
- added asynchronous offline-compatible `scoreboards.addScore()`,
  `getScores()`, `getPersonalBest()` and `getScoreboards()` callback shapes;
- added case-insensitive compiled image/image-table filename recovery without
  package-name or asset-specific substitutions;
- log a requested image-table path when no compiled resource can be found.

## Result

The real package passes a dedicated semantic probe for playback offsets,
volume, one-shot completion, looping file players, stencil clearing and the
scoreboard callback. Fresh-runtime probes then open main menu, score menu,
credits, handbook, tasks, upgrades, Training, the main game and Recap. The
main-game probe runs 1,000 logical frames; every scene finishes with zero Lua
errors.

Regressions pass for key repeat/system glyph fallback, callable scenes, real
font families, the 92-method game-compatibility harvest, deep SFX startup,
input responders, crank and synth. Maze runs 900 frames and Duel Of Shadows
runs its 1,800-frame boss path with zero Lua errors. WOOD reaches its playable
room at 20 FPS and keeps all eight progression checksums.

All Playdate API calls statically referenced by Hillslide's supplied Lua
modules now exist in PogoDate. This does not claim complete Playdate OS
emulation: scoreboard results are offline placeholders and actual audio loop
subranges are still approximated by the current decoded-audio backend.
