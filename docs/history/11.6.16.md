# STEP11.6.16 — Playdate API harvest 1

## Before

STEP11.6.15 made Pulp controls playable, but broad compatibility was still
blocked by missing leaf APIs commonly used by bundled CoreLibs and independent
Lua games: most geometry types, JSON encoding, several graphics primitives,
display-state getters and useful system-menu item objects.

## Changes

PogoDate now implements rect, point, size, vector, line-segment, polygon, arc
and affine-transform operations; compact/pretty/file JSON encoding; triangle,
polygon and ellipse drawing; renderer-backed display/graphics getters; and
mutable menu items with values and callbacks. These are generic runtime APIs,
with no new package-name workaround.

## Result

The new API-harvest regression passes alongside input, crank, synth, Maze,
Duel and WOOD tests. WOOD still reaches its playable room at its authored
20 FPS and produces the same progression frame checksums as STEP11.6.15.
