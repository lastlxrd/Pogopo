# STEP11.6.11 — Lua Playdate synth support

## Before

STEP11.6.10 polished Maze and Duel gameplay, but some Lua PDX packages still failed during startup because `playdate.sound.synth` was missing.

## Changes

`playdate.sound.synth` is now backed by Pogopo's four-voice mixer with managed per-synth voices, waveform generation, note playback, ADSR envelopes, transpose and common Playdate synth controls. :contentReference[oaicite:0]{index=0}

## Result

Lua packages can now create and play independent synth voices without interrupting samples, music, UI audio or other synths, while the existing Maze, Duel, Celeste, Godspeed and Frogger regressions remain stable.
