# STEP11.5 — Real PFT fonts and broader Playdate compatibility

## Before

STEP11.4 improved general PDX loading and frame pacing, but Onebit Frogger still used a fallback font and more complex Lua Playdate games exposed additional missing APIs.

## Changes

Real Playdate PFT font parsing and rendering were added together with broader display, timer, sprite, collision, image and audio compatibility required by Onebit Frogger and Godspeed. :contentReference[oaicite:0]{index=0}

## Result

Onebit Frogger now renders its original font correctly and both Frogger and Godspeed complete host runtime tests with zero errors, while native ARM `pdex.bin` packages remain unsupported.
