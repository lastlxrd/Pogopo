# STEP11.6.13 — External PDZ load/run for Pulp packages

## Before

STEP11.6.12 completed the Lua crank surface, but Pulp-style packages such as WOOD still stopped on the first logical frame because `playdate.file.load()` was missing.

## Changes

`playdate.file.load()` and `playdate.file.run()` now support deferred external PDZ bytecode loading with optional environments, opcode normalization, returned values, package sandboxing and clean error handling. :contentReference[oaicite:0]{index=0}

## Result

Pulp-style packages can now load and execute standalone data PDZ files at runtime, while the new 20 FPS load/run probe and all existing crank, synth, Maze, Duel, Celeste, Godspeed and Frogger regressions remain stable.
