# STEP11.2 — SD Playdate PDX/PDZ loader

## Before

Celeste ran at about 30 FPS, but Playdate games were still embedded in the firmware instead of being loaded from the SD card.

## Changes

An SD package browser and loader for `.pdx` folders, `main.pdz`, Playdate images and original audio assets were added. :contentReference[oaicite:0]{index=0}

## Result

After building and flashing, the browser reported no mounted SD card without a card inserted, but with the card present it froze, triggered vibration and restarted the menu when opening the Playdate games folder.
