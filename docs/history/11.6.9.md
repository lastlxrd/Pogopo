# STEP11.6.9 — Maze controls and Level Complete frame pool

## Before

STEP11.6.8 restored the shared PDX input mapping, but Maze still needed its own corrected horizontal controls and Y-axis behavior while Level Complete continued causing heavy Lua garbage collection.

## Changes

Maze now receives bundle-specific horizontal button and Y-axis corrections without affecting other PDX games, and the reusable PSRAM image-plane threshold was lowered to 32 KiB so its 324 x 137 Level Complete frames no longer stay in the Lua heap. :contentReference[oaicite:0]{index=0}

## Result

Maze controls now match its own input expectations while the Level Complete animation avoids the previous large per-frame Lua allocations.
