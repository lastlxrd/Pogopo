# STEP11.0.1 — PDSnake CMake fix

## Before

STEP11.0 could not build because the Playdate component used a non-scriptable CMake command during early component expansion.

## Changes

The source-file properties were moved after component registration and the build target was pinned to ESP32-S3.

## Result

After building and flashing, PDSnake launched successfully and worked correctly, confirming that the Lua compatibility runtime was functional.
