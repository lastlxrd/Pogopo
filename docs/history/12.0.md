# STEP12.0 — SharpBit startup animation

## Before

The stable firmware booted directly into the launcher without a dedicated startup animation.

## Changes

A 111-frame SharpBit startup animation was added at 10 FPS, with frames 107–111 looping until a fresh button press. :contentReference[oaicite:0]{index=0}

## Result

The console now plays the full startup animation on boot and enters the launcher only after the looping ending is dismissed.
