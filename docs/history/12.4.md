# STEP12.4 — Short interactive SharpBit startup

## Before

STEP12.3 used a longer 122-frame startup animation before entering the launcher.

## Changes

The startup sequence was replaced with a 25-frame `pogopointro` animation that loops frames 12–15 until input and then plays frames 16–25 as the outro. :contentReference[oaicite:0]{index=0}

## Result

Boot is now much shorter and interactive, while the launcher opens only after the final outro frames complete and the stable white shutdown behavior remains unchanged.
