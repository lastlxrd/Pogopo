# STEP11.6.12 — Complete Lua crank compatibility surface

## Before

STEP11.6.11 added Playdate synth support, but some Lua PDX packages still stopped during startup when they reached the missing crank API.

## Changes

The complete documented Lua crank surface was added, including position, change, ticks, dock state, crank callbacks, input-handler routing and the shared crank-indicator object, with a deterministic neutral state on Pogopo until physical crank hardware exists. :contentReference[oaicite:0]{index=0}

## Result

Packages that inspect or initialize Playdate crank functionality can now continue past startup, while crank API probes, UBSan and the existing Maze, Duel, Celeste, Godspeed and Frogger regressions remain stable.
