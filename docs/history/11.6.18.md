# STEP11.6.18 — PogoDate stack-safe startup

## Before

STEP11.6.17 launched Tochi II Senshi, but selecting Hillslide rebooted the
device with FreeRTOS reporting a stack overflow in `pogopo_os`. The failure
happened before the PogoDate API banner, so it was not a missing Lua API. The
startup sound preloader recursively traversed the package tree while retaining
large path buffers in every 8 KiB task-stack frame.

## Changes

The short-sound scan is now an iterative, bounded breadth-first traversal. Its
64-directory queue and all large path/stat scratch storage live in PSRAM and are
released before Lua starts. The UI/runtime task stack is increased from 8 KiB
to 12 KiB for nested CoreLib import chains. PDX startup now logs the task's
minimum free stack before and after loading, while the sound scan reports its
directory count, skipped entries and cached bytes.

## Result

A synthetic package with seven nested sound directories starts, caches 61,020
bytes and runs without errors. The rebuilt suite also passes the STEP11.6.17
game-compatibility test, input, crank, synth, Maze 900-frame and Duel 1,800-frame
regressions. WOOD's eight progression captures remain byte-identical.

The actual Hillslide package is only present on the user's SD card, so the final
proof is the hardware run. If startup now reaches the `PogoDate API` banner and
then stops, the stack bug is fixed and the next complete Lua error identifies a
separate compatibility API to implement.
