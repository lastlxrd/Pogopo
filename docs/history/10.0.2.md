# STEP10.0.2 — GBA cache removal and audio test

## Before

STEP10.0.1 ran GBA games at roughly 5–10 FPS with cleaner but still impractical audio.

## Changes

The experimental opcode cache was removed, direct opcode fetching was restored and slow-game audio handling was reworked.

## Result

After flashing, performance remained around 8–10 emulated FPS with only 4–5 FPS on the LCD, while audio overflow and dropped samples increased, making this build worse than the previous test.

## Note

The runtime log still reported `code=1` instead of the expected `code=OFF`, suggesting that the cache removal was not active in the tested build.
