# STEP13.4 — Pogofont system typography

STEP13.4 makes the embedded Pogofont family the visual system font for the
Pogopo shell and the Playdate compatibility runtime.

## Changes

- The system Regular and Regular Italic faces are available through the
  Playdate font API.
- `playdate.graphics.getSystemFont(2)` selects the italic system face.
- A missing or unsupported `.pft` now falls back to Pogofont instead of the
  legacy 5x7 bitmap face.
- Fallback fonts read their requested pixel size from names such as
  `Roobert-11` and `Roobert-20`, then scale the nearest packed Pogofont face.
- Missing glyphs inside an otherwise valid game font use Pogofont at that
  font's own height.
- Valid game-provided PFT fonts are preserved so a game's intended art
  direction and layout are not replaced globally.
- Playdate and Game Boy launch/error panels, power messages, and common GUI
  header/footer chrome use Pogofont Regular or Regular Italic.

## Verification

- All six packed faces (Regular/Italic at 14, 22, and 24 px source sizes)
  validate against the embedded 745,556-byte asset blob.
- System Regular, system Italic, and a requested 20 px missing-font fallback
  render through the Playdate API with zero Lua errors.
- XTRIS effects regression: 820 frames, zero runtime errors and zero effect
  fallback events.
- Binairo Continue regression: 360 frames, zero errors and zero stops.
- Font, GUI, and Playdate runtime sources pass host compilation with warnings
  treated as errors.

## Hardware check

1. Open the Playdate browser and confirm its title, selected row, metadata,
   status, and footer match the Game Boy browser style.
2. Launch a game that uses the Playdate system font and verify Regular and
   Italic remain readable at the compact default size.
3. Launch games with 11 px and 20 px fallback font requests and confirm their
   original line spacing is retained.
4. Confirm XTRIS and other games with bundled PFT fonts keep their own font
   design while unsupported characters still render.
