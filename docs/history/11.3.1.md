# STEP11.3.1 — Playdate image rotation compatibility

## Before

Onebit Frogger loaded from SD but stopped because `playdate.graphics.image:drawRotated()` was missing.

## Changes

The Playdate-compatible `drawRotated()` image method was added with rotation, scaling, clipping, stencil and draw-mode support. :contentReference[oaicite:0]{index=0}

## Result

Frogger progressed past image rotation and started its update loop, but then stopped because `btnp()` accepted only numeric button IDs while the game passed a string.
