# STEP11.1 — Celeste Classic compatibility test

## Before

PDSnake built and ran correctly, proving that the basic Playdate Lua runtime worked.

## Changes

Celeste Classic and the additional Playdate sprite, tilemap, collision, image and input APIs required by the game were added.

## Result

After building and flashing, Celeste launched but ran at only about 5 FPS, making the first port effectively unplayable.
