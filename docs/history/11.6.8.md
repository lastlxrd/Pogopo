# STEP11.6.8 — Stable PDX input mapping

## Before

STEP11.6.7 improved rendering performance but introduced broad left/right button and BMI270 X-axis inversions at the Playdate boundary.

## Changes

The STEP11.6.7 input inversions were rolled back so physical left/right buttons and the BMI270 X axis again use the previously established hardware mapping, while its pooling, native tilemap, font and START-to-A improvements remain unchanged. :contentReference[oaicite:0]{index=0}

## Result

PDX controls now use the stable shared hardware mapping again without game-specific patches, with Maze requiring one fresh in-game calibration after flashing.
