# STEP11.6.15 — Playdate responder stack and Pulp controls

## Before

STEP11.6.14 let Pulp games load, render and play audio, but global Playdate button callbacks were never reached so physical controls did nothing.

## Changes

Button events now follow Playdate's responder stack from pushed input handlers down to the global `playdate` callbacks, including masking and first-handler behavior, without changing existing polled input or package-specific mappings. :contentReference[oaicite:0]{index=0}

## Result

WOOD now advances through its beach dialog, enters the playable room and responds to D-pad movement while preserving its authored 20 FPS target and passing the existing regression suite.
