# STEP11.6.1 — Noble system fonts and unambiguous firmware identification

## Before

STEP11.6 expanded Lua PDX compatibility, but a previously unseen Noble Engine package stopped on the missing Playdate system-font API and older flashed builds were difficult to distinguish from the current source.

## Changes

`playdate.graphics.getSystemFont()` and `getFont()` were added with persistent system-font handling, while explicit STEP11.6.1 identification lines were added to the hardware log. :contentReference[oaicite:0]{index=0}

## Result

Noble Engine packages can now access the expected system-font API, and serial output clearly confirms whether the correct STEP11.6.1 firmware is actually running.
