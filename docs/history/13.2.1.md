# STEP13.2.1 — Alpha-correct Power Outro

## Before

STEP13.2 added the interactive Power Outro, but transparent pixels in the supplied animation were flattened to black instead of preserving the interrupted menu or game underneath.

## Changes

The Outro now keeps the real Aseprite alpha channel and renders only opaque black or white artwork while transparent pixels leave the captured framebuffer untouched. :contentReference[oaicite:0]{index=0}

## Result

The Power Outro now progressively draws over the existing screen without blacking out transparent areas, while forward, reverse and shutdown timing remain unchanged.
