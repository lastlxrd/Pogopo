# STEP11.6.7 — PDX input axes, transition latency and native tilemaps

## Before

STEP11.6.6 fixed Maze completion and Duel portal detection, but Playdate button/IMU axes were still reversed and both games retained expensive rendering paths during transitions and tilemap-heavy scenes.

## Changes

PDX left/right input and BMI270 X mapping were corrected, large transient Maze images now reuse a PSRAM pixel pool, Duel tilemaps render through a native clipped C++ path, zero-degree scaled sprites use the fast scaler and Playdate Ⓐ/Ⓑ symbols are supported by the fallback font. :contentReference[oaicite:0]{index=0}

## Result

Maze now completes its level transition and returns to the menu without errors, while Duel Of Shadows greatly reduces Lua image-table calls and all listed package regressions remain stable.
