# STEP11.6.30 — render/audio compatibility and rounded-rectangle spans

This step follows the STEP11.6.29 hardware results for Novena,
Illumination, Loopsy and XTRIS.

## Compatibility fixes

- Added the `playdate.sound.instrument` object lifecycle used by Pulp exports:
  voices, transpose, note on/off, all-notes-off and stereo volume state.
- `graphics.setLineWidth()` now accepts finite fractional Lua numbers and
  converts them to the integer native line width. This fixes Loopsy's animated
  menu background.
- `graphics.pushContext()` without an image now preserves the current render
  target instead of switching to the LCD framebuffer.
- Graphics contexts now save and restore target, clip, stencil, font, color,
  pattern, draw mode, line width, stroke location, draw offset and font
  tracking. This prevents Panels text drawing from leaking inverted/fill-white
  state into Illumination's panel canvases.

## Performance

- Filled and outlined rounded rectangles are rasterized as horizontal spans.
  Pattern, stencil, NXOR, clipping and line-width behavior still route through
  the shared compositor.
- The XTRIS 1.1.2 host menu test dropped from about 2.0 ms to 0.5 ms per frame,
  approximately 4x faster. Hardware timing must be verified on Pogopo.

## Validation

- Novena 1.3: 408 Lua frames, zero errors.
- Illumination 1.2.1: 180 frames, zero errors; the first comic panel is visible.
- Loopsy 1.3: 600 frames, zero errors.
- XTRIS 1.1.2: 300 frames, zero errors.
- Maze: 3000 ticks / 900 Lua frames, zero errors.
- Hillslide: all nine scenes; training 530 frames and gameplay 1030 frames,
  zero errors.

Pulp sequences retain timing and lifecycle compatibility, but STEP11.6.30 does
not add a complete MIDI sequencer/mixer. A Pulp title can therefore run while
its generated MIDI music remains silent.
