System

Hardware

pogopo is built around a custom ESP32-S3 PCB with a 400 × 240 monochrome display, physical controls, audio, storage, motion sensing, haptics, and battery management.

Hardware summary

MCU and memoryDual-core ESP32-S3, 16 MB flash, 8 MB Octal PSRAM
DisplaySharp LS027B7DH01, 400 × 240, 1-bit Memory LCD
StoragemicroSD over four-bit SDMMC
InputD-pad, A, B, Start, Menu via TCA9555; Power on a dedicated GPIO
MotionBMI270 six-axis IMU
AudioMAX98357A digital I²S amplifier
PowerBQ24295 charger/power-path controller with gated battery ADC measurement

Core components

ESP32-S3

The MCU runs PogopoOS, device services, UI rendering, application code, and the Game Boy runtime. The current board exposes 16 MB of flash and 8 MB of PSRAM.

What it does
System control, graphics, application runtime, emulation, and peripheral coordination.
Interface
Native GPIO, SPI, I²C, I²S, SDMMC, ADC, and FreeRTOS tasks on two cores.
Why it was chosen
It combines two cores, embedded peripherals, external-memory support, and the ESP-IDF software stack in one MCU.

Sharp LS027B7DH01 Memory LCD

The 400 × 240 panel defines pogopo’s crisp 1-bit visual language. PogopoOS keeps a 12 KB framebuffer, updates dirty rows, and uses a fast full-frame path when needed.

What it does
Displays the launcher, applications, games, diagnostics, and shutdown animation.
Interface
SPI2 at 14 MHz: SCK GPIO12, MOSI GPIO11, active-high CS GPIO14; VCOM is maintained by a dedicated task.
Why it was chosen
It provides a readable monochrome image and retains static pixels without continuous full-screen refresh.

BMI270

The six-axis IMU provides acceleration and angular-rate data for diagnostics and future motion-aware applications.

What it does
Reports device movement and orientation-related sensor data.
Interface
I²C at address 0x68, SDA GPIO8, SCL GPIO9, interrupt GPIO18.
Why it was chosen
It adds compact motion input without consuming the primary control GPIOs.

MAX98357A audio

The digital amplifier receives PCM audio from the ESP32-S3. The Game Boy path runs at a fixed 32,768 Hz with 16-bit stereo I²S data.

What it does
Converts the firmware’s digital audio stream into amplified speaker output.
Interface
I²S: DATA GPIO38, BCLK GPIO39, LRCK GPIO40.
Why it was chosen
A digital I²S path keeps sample timing under firmware control and avoids an external analog DAC stage.

microSD storage

The card holds ROMs, WAV files, and other user content mounted through ESP-IDF’s FAT VFS.

What it does
Provides removable storage and file-based content loading.
Interface
Four-bit SDMMC: D0–D3 GPIO5/4/16/15, CLK GPIO6, CMD GPIO7.
Why it was chosen
The four-bit bus provides more transfer bandwidth than a basic SPI card connection.

TCA9555 and controls

The I/O expander reads the D-pad, A, B, Start, and Menu as one active-low port. The firmware uses a 10 ms I²C timeout and treats a failed sample as released to avoid stuck input.

What it does
Expands the MCU’s input capacity for eight front-panel controls.
Interface
I²C 0x20, interrupt GPIO21. P8 Top, P9 Down, P10 Left, P11 Right, P12 B, P13 A, P14 Menu, P15 Start.
Why it was chosen
It reduces direct GPIO usage while allowing the full button state to be read together.

Haptics

A vibration motor provides short UI and gameplay feedback.

What it does
Adds tactile confirmation for interactions.
Interface
GPIO3 through the board’s vibration drive circuit.
Why it was chosen
It communicates feedback without requiring another visual or audio cue.

Battery and power management

The BQ24295 is detected at I²C address 0x6B. Firmware reads charge and fault status, samples the battery through a gated ADC path, distinguishes short and held Power presses, blocks ship mode while USB is present, and physically clears the LCD before shutdown.

What it does
Charging and power-path status, battery measurement, user power events, and final ship-mode shutdown.
Interface
I²C plus Power GPIO17, charger interrupt GPIO41, battery ADC GPIO1, measurement gate GPIO2.
Why it was chosen
It gives firmware visibility into charge state and a controlled low-power shutdown path.

Custom PCB

The custom board integrates the ESP32-S3, display connection, SDMMC bus, I²C peripherals, digital audio, controls, haptics, and power-management signals used by PogopoOS. Bring-up diagnostics probe the TCA9555, BMI270, and BQ24295 and print their register state to the serial monitor.

Enclosure
