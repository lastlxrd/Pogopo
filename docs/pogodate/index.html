Experimental runtime

PogoDate

PogoDate runs selected Lua-based Playdate packages on ESP32-S3. It is an independent compatibility layer, not an emulator of Playdate hardware and not an official Panic product.

Package support

Lua source and Lua PDZ packages can run when they stay within the implemented API surface. Images, image tables, fonts, audio, sprites, timers, easing, clipping, buttons, and accelerometer input are available, but compatibility is still verified title by title.

Native pdex.bin games are not supported because Playdate native code targets ARM while the ESP32-S3 uses Xtensa. PogoDate does not claim complete Playdate SDK coverage.

Implemented areas

The runtime combines Lua 5.4 and PDZ loading with a 400 × 240 monochrome graphics layer. It implements the common drawing, image, image-table, font, sprite, timer, easing, pattern, and clipping paths used by the titles tested so far.

Audio support includes samples, file players, synthesizer paths, PCM mixing, and IMA ADPCM decoding. Physical buttons map to the Playdate input API, and the BMI270 provides accelerometer data. Compatibility and performance fixes remain general where possible, with per-title testing used to expose missing behavior.

Current limitations

A title reaching its menu does not mean every gameplay scene, transition, audio format, SDK call, or accessibility mode is implemented. Native Playdate executables cannot run through this runtime.

Reporting a problem

Include the title and version, exact reproduction steps, expected and actual behavior, a photo or video, and serial output beginning at Starting ... through the first error or several PERF PD lines. Do not redistribute commercial game packages.
