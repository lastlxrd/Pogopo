Experimental runtime

PogoDate

PogoDate runs selected Lua-based Playdate packages on ESP32-S3. It is an independent compatibility layer, not an emulator of Playdate hardware and not an official Panic product.

Package support

Lua source / Lua PDZSupported when the title uses implemented APIs.
Images, image tables, fonts, and audioPartially supported; compatibility is expanded and verified title by title.
Native pdex.binUnsupported. Playdate native code targets ARM while ESP32-S3 uses Xtensa.
Complete Playdate SDKNot yet implemented.

Implemented areas

  • Lua 5.4 runtime and PDZ loading
  • 400 × 240 monochrome rendering, patterns, images, and image tables
  • Sprites, timers, easing, fonts, clipping, and common drawing APIs
  • Samples, file players, synthesizer paths, PCM mixing, and IMA ADPCM decoding
  • Buttons and BMI270 accelerometer mapping
  • Per-title compatibility and performance fixes

Current limitations

A title reaching its menu does not mean every gameplay scene, transition, audio format, SDK call, or accessibility mode is implemented. Native Playdate executables cannot run through this runtime.

Reporting a problem

Include the title and version, exact reproduction steps, expected and actual behavior, a photo or video, and serial output beginning at Starting ... through the first error or several PERF PD lines. Do not redistribute commercial game packages.
