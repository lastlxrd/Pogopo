playdate compatibility

PogoDate runs selected Lua-based Playdate packages on ESP32-S3. It is a compatibility layer, not an emulator of Playdate hardware and not an official Panic product.

Package support

PackageStatus
Lua source / Lua PDZSupported when the game uses implemented APIs
Assets: images, image tables, fonts and audioPartially supported; compatibility is expanded game by game
Native pdex.binUnsupported: Playdate native code targets ARM, while ESP32-S3 uses Xtensa
Full Playdate SDKNot yet implemented

Current work

  • Lua 5.4 runtime and PDZ loading
  • 400 × 240 monochrome rendering and image-table support
  • Sprites, timers, easing, fonts, patterns and common drawing APIs
  • Sample, file player, synthesizer and IMA ADPCM audio paths
  • Buttons and BMI270 accelerometer mapping
  • Per-title compatibility and performance fixes

Reporting a game problem

Include the game/version, the action that triggers the issue, a photo or video, and serial output beginning at Starting ... through the first error or several PERF PD lines. Do not distribute commercial game files.

Compatibility changes quickly. A game reaching its title screen does not guarantee that every scene, audio format or SDK call is implemented.
