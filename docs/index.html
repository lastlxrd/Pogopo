pogopoOS

Firmware and hardware documentation for the modular pogopo ESP32-S3 handheld.

pogopo combines a 400 × 240 Sharp Memory LCD, physical controls, audio, motion sensing, haptics and SD-card game libraries. The current firmware includes Game Boy emulation and the experimental PogoDate Lua compatibility runtime.

Work in progress. Game Boy support is stable. Playdate support is an independent compatibility project and currently implements only a subset of the Playdate SDK.
