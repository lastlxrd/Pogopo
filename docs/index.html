pogopoOS is firmware for a custom ESP32-S3 handheld with a 400 × 240 Sharp Memory LCD, Game Boy emulation, an experimental Playdate Lua compatibility runtime, audio, motion controls and haptics.

get startedread the FAQ
Work in progress. Game Boy support is stable. Playdate support is an independent compatibility project and currently implements only a subset of the Playdate SDK.
