pogopo

pogopo is a compact handheld game console and modular pocket platform with a custom PogopoOS firmware, a monochrome Sharp Memory LCD, and a deliberately recognizable 1-bit interface.

What is pogopo?

The project is not only a handheld for games. It is intended as a small platform that can change with the user: a game console today and a compact tool for hardware or software experiments later. The right side is reserved for a mechanical and electrical expansion area where interchangeable modules can connect.

I designed the device around a custom PCB and implemented the current ESP-IDF firmware stack, device drivers, launcher, system services, 1-bit UI, power flow, diagnostics, and emulator integration described in these pages.

Current capabilities

  • Animated 1-bit launcher, settings, library screens, startup sequence, and a Power-button quick menu.
  • Physical controls, audio, haptics, motion sensing, battery status, and microSD storage.
  • Game Boy emulation using Peanut-GB and MiniGB APU, with a full-rate 59.7 Hz emulation clock and approximately 29.9 Hz LCD presentation.
  • Reusable PogopoOS components for graphics, input, audio, storage, motion, power, settings, and applications.
  • A work-in-progress modular expansion concept on the right side of the enclosure.

PogopoOS

PogopoOS is a purpose-built embedded firmware stack rather than a Linux distribution. It starts hardware services, owns the Sharp LCD framebuffer, routes input and power events, and runs applications through a shared app manager. Time-sensitive emulator and audio work is separated across the ESP32-S3 cores with pinned FreeRTOS tasks.

Modularity

The planned right-side expansion area combines mechanical attachment with an electrical connection. The goal is to support user-swappable hardware without turning the main console into a one-purpose device. Connector choice, electrical limits, module discovery, and the first verified modules are still work in progress and are documented as such.
