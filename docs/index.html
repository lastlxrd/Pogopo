Modular handheld platform

Pogopo

A custom ESP32-S3 handheld built around a 400 × 240 Sharp Memory LCD, physical controls, audio, motion sensing, haptics, removable storage, and PogopoOS.

Early development

Pogopo hardware and PogopoOS are active engineering projects. Interfaces, compatibility, and documentation may change between checkpoints.

What is working

The current firmware includes board bring-up, a responsive 1-bit launcher, settings and diagnostics, Game Boy emulation, and an experimental PogoDate runtime for selected Lua-based Playdate packages.
